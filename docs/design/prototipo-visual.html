Sala de aula · Design

Identidade visual e explicações interativas

Um guia de estilo e um padrão de componente reutilizável (VisualStep) para explicar algoritmos e estruturas de dados passo a passo, com dois protótipos funcionando.

Guia visual Protótipo 1 · Busca binária Protótipo 2 · Pilha e fila

Princípios

  • Uma ideia por passo. Cada passo muda uma coisa na tela e tem uma frase explicando o porquê.
  • Cor é estado, nunca enfeite. As cores de visualização têm significado fixo em todas as aulas.
  • Código e desenho andam juntos. A linha do pseudocódigo em execução fica destacada ao lado da animação.
  • Prever antes de ver. Em pontos-chave, o aluno responde o que vai acontecer antes de avançar.
  • O aluno controla o tempo. Sempre há voltar, avançar, reproduzir e velocidade. Respeita "reduzir movimento".

Anatomia do componente VisualStep

Todo visual de algoritmo usa a mesma estrutura. Só o palco muda entre aulas; o resto é reaproveitado.

1 · Cabeçalho

Título e entrada

Nome do conceito e campo para o aluno mudar os dados de entrada.

2 · Palco

Desenho do estado

Array, pilha, grafo ou árvore, colorido pelos estados semânticos, com legenda.

3 · Pseudocódigo

Linha atual

Destaque na linha que gerou o passo, para ligar o desenho ao código.

4 · Variáveis

Estado interno

Valores atuais (lo, mid, hi, topo…) em fonte mono.

5 · Narração

O porquê

Uma ou duas frases por passo, em linguagem simples.

6 · Controles

Tempo do aluno

⏮ ◀ ▶ ⏭, reproduzir/pausar, velocidade e barra de progresso. Atalhos: ← → espaço.

7 · Previsão

Pergunta no meio

Em passos marcados, o avanço trava até o aluno arriscar uma resposta.

8 · Quiz final

Fixação

Perguntas de múltipla escolha com explicação do erro e do acerto.

Versão mobile

O mesmo componente se reorganiza abaixo de 640 px. Nada é removido, só reordenado para caber na mão e no polegar.

Ordem

Palco primeiro

Palco → narração → controles → painéis. Desenho e explicação ficam juntos na tela.

Controles

Barra fixa no rodapé

Fica presa embaixo enquanto a aula está visível. Botões de 44 px, ao alcance do polegar.

Gesto

Deslizar para avançar

Arrastar o palco para a esquerda avança, para a direita volta. No desktop, as setas do teclado.

Painéis

Abas compactas

Código, Variáveis e Custo viram abas, em vez de uma coluna lateral longa.

Palco

Uma linha só

Arrays encolhem para caber sem quebrar linha. Comparações (pilha × fila) continuam lado a lado.

Navegação

Abas roláveis

As abas do topo rolam na horizontal e ficam fixas. Quiz com alvos de toque de 48 px.

Formato de dados de um passo

{
  state:   { ... },        // o que o palco desenha
  line:    3,              // linha destacada do pseudocódigo
  vars:    { lo: 0, mid: 4, hi: 9 },
  text:    "Comparamos a[4] = 23 com o alvo 31…",
  predict: {               // opcional: trava o avanço
    q: "Qual será o próximo mid?",
    options: [6, 7, 5], answer: 7, why: "…"
  }
}

O algoritmo roda uma vez e gera a lista de passos. O componente só navega por ela, então voltar e avançar é trivial e qualquer aula nova é só uma função geradora + um palco.
